# 岁己 · 雾港行动

默认入口现为原创 3D 单人战术搜打撤：在码头整备、进入雨蚀港区搜索和交战，然后选择南岸接应或供电后开放的北侧撤离。三阶段委托逐步引导至医疗站、雷达与归航结局。通关后开放更多巡逻兵的高危自由行动。

使用 React Three Fiber + Three.js。可操作主角为依照红帽立绘制作的 Q 版三维岁己：白色双马尾、红瞳、红帽、羽翼、格纹裙、金色光环和小鸟同伴；基地可左右旋转查看，同一角色进入行动并随移动、低姿、换弹和射击产生动画。港区新增雨后铺装、钢板材质、工业构件、晨雾、水面和港灯。游戏规则、存档和渲染分离，集中于 `src/extraction/`。玩法规格见 [EXTRACTION_UPGRADE.md](EXTRACTION_UPGRADE.md)，美术重制见 [VISUAL_OVERHAUL.md](VISUAL_OVERHAUL.md)，素材来源与生成规格见 [素材说明](public/assets/fogharbor/README.md)。

| 动作 | 键位 |
| --- | --- |
| 移动 / 冲刺 / 低姿 | WASD / Shift / C |
| 瞄准 / 射击 / 精准瞄准 | 鼠标 / 左键 / 按住右键 |
| 换弹 / 医疗 | R / H |
| 搜索与设施互动 | E |
| 背包 / 战术地图 | Tab / M（行动继续） |
| 暂停 / 全屏 | Esc / F |

触屏使用左摇杆移动、右摇杆瞄准射击，以及 HUD 按钮。设置中可以静音、降低画质和减少环境与界面动态；低画质使用简化材质并关闭阴影和后处理，减少动态会停止呼吸、发梢、羽翼和环境装饰运动。失焦自动暂停。

出击扣除已部署装备，成功撤离返还剩余装备、药品与战利品。死亡仅保留保险格，普通背包和武器留在地图供下一轮回收；再次失败覆盖旧遗体。刷新、关闭页面视为行动中断。无枪时可领取免费救援套装。仓库支持出售、采购、背包与仓库扩建、存档导入导出；满仓溢出物资自动出售。

独立存档键为 `sui-fogharbor.save.v1`，含 `version: 1`、`credits`、`stash`、`guns`、`armors`、`meds`、`suppressors`、`packLevel`、`stashLevel`、`contract`、`raids`、`wins`、`kills`、`lost`、`active`、`last`、`settings`。浏览器自动化只通过此存档键布置场景、重新加载后由应用归一化，不直接修改运行中规则。公开 `render_game_to_text()` 描述世界米制坐标、玩家、物资、敌人、撤离和持久状态；`advanceTime(ms)` 使用固定小步推进模拟。

```powershell

npm run build
npm run preview -- --host 127.0.0.1 --port 4175
# 另一终端，Node.js 24
```

# 岁己 · 借光归来（保留模式）

此保留模式是五个房间的短局动作寻宝：从归灯站出发，取回温室灯芯，决定直接返回还是继续挑战钟楼。灯芯会强化攻击，同时唤醒回程守卫；失败后可直接重试，基础装备与动作不会丢失。

首次成功后才开放回旋羽选择；带回第一件纪念品后才出现收藏入口。原版《空响撤离》仍可从主界面右下角“原版远征”进入，也可直接访问 `/knight/?mode=legacy`。

两套 2D 模式的存档互相独立：借光归来为 `sui-lantern-run.save.v1`，原版仍为 `sui-echoes-below.save.v1`。新版不会读取、迁移或重置原版存档。

## 新版操作

| 动作 | 键位 |
| --- | --- |
| 移动 | A / D 或左右方向键 |
| 跳跃 | Space |
| 羽刃 / 回旋羽 | J / X / 鼠标左键，可按住连续攻击 |
| 方向攻击 | W / ↑ 上劈；空中 S / ↓ 下劈 |
| 冲刺 | K / Shift / 鼠标右键 |
| 互动 | E / Enter，也可点击情境按钮 |
| 暂停 | Esc / P |
| 全屏 | F |

触屏设备有移动、瞄准、跳跃、攻击和冲刺按钮。浏览器失焦时暂停旅途；声音可在右上角开关。

操作提示以方向键、空格、鼠标左键、Shift 和 Enter 的图示呈现。开场、首次交战、台阶和互动点会高亮相关操作；已学过的操作会记录。右上角键盘图标或暂停页可切换显示，暂停页也可重新查看引导。隐藏提示不会移除触屏操作按钮。

雨歇茶在满血且不需要补充余光时会保留，并明确提示；实际喝下会显示恢复量。喝完后，互动点显示“雨歇茶已喝完”。

两种武器的区别：羽刃为近战挥击，出手间隔 0.34 秒，可下劈反弹与反射弹体；回旋羽为远程投掷，间隔 0.75 秒，去程和回程各可命中一次，没有贴身挥砍判定。武器选择处显示相应属性。

横向镜头带有死区、方向稳定时间和小幅缓慢前视，不会因为原地切换朝向而快速左右摆动。

## 原版：空响撤离

一款把类《空洞骑士》的横版动作手感与“搜打撤”风险循环结合起来的浏览器游戏原型。岁己 SUI 坠入寂羽空洞，需要把装备带进远征、搜集物资、从撤离点安全返回，并逐步重启信号回到饼干岁们的直播间。

当前 `0.2` 已是可从头玩到结局的双地图原型，而非静态界面稿。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```powershell
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:4175/knight/`。生产构建使用：

```powershell
npm run build
npm run preview
```

## Demo 内容

- 简化基地：默认显示五个装备槽、4×5 随身背包和 9×10 安全仓库；工作台、拾荒交易台、线索簿与入口选择各自独立。
- 物品具有真实二维占格，例如修补片 1×2、回声核心 3×3；支持精确落点预览、旋转、自动找空位、堆叠合并、拆分、双击转移和自动整理。
- 一张 6,400×2,200 的二维房间地图，包含横向房间、回声竖井、折返支路、隐藏跳跳乐补给区、天线墓园与沉眠温室高线。
- 普通入口会在同一区域的多个安全点间轮换，维护电梯则直接抵达真正的深层区域；温室风顶提供额外撤离点。完成两侧校准后，天线深场会开放冠顶终端接驳，方便确认结局与复访。
- 跑跳、横劈、上劈、可反弹下劈、击退、受击无敌帧、武器差异、普通冲刺与免伤黑冲、地刺与坑洞、三类敌人与 Boss；偶数轮远征会出现可预警、可横移/跳跃躲避脉冲的回波哨兵。
- 四种头部效果：小红帽击败敌人后间隔回血，小蓝帽高亮并指引宝箱/遗失回声，小花帽强化糖浆，小猫帽受伤后短暂加速。
- 搜刮箱、材料、消耗品、装备、收藏品、地图羽片和回声核心；普通补给箱按远征编号轮换补给组合，关键物与剧情战利品保持稳定。蓄水池、温室和深场分别藏有重击、机动和长距武器选择。
- 近端与深层撤离点；安全撤离后战利品仍留在随身背包，回基地后再卸入安全仓库。
- 下一轮可在死亡地点找回一次遗失回声；再次死亡会用新回声覆盖旧回声。
- 基地不再下发任务清单；经过区域、聆听回声或发现关键物会写入线索簿，验证后自动归档，地图与新入口逐步显形。
- 羽币单件/批量买卖、整组出售、阶段性货品解锁和物品图鉴构成轻量成长/收集循环。
- 维护电梯永久捷径、深层出生点、浏览器自动存档、JSON 导入导出。
- 击败守卫后可以在墓园路线通过深场折跃门进入天线深场，并能从西向阵列折返；整轮远征的装备、背包、生命和蓝甲会保留。拾取并安全带回回声核心后永久解锁深场；在深场校准东西阵列并守在冠顶终端完成锁定，触发首个通关动画：“结局一 · 尚未归巢”。失败远征不会确认阵列校准。
- 网络边界和地图注册表已抽离，后续可接权威服务器并加入更多地图。

## 设计与代码入口

- `GAME_DESIGN.md`：完整玩法、叙事、经济与后续路线。
- `DEMO_PLAN.md`：第一版范围、验收场景与技术选择。
- `src/game/RaidScene.ts`：远征世界、动作、战斗、交互与结算。
- `src/components/BaseScreen.tsx`：基地、仓库、配装和目标界面。
- `src/services/saveRepository.ts`：自动存档、导入导出和异常退出结算。
- `src/services/gameNetworkBoundary.ts`：未来联网服务的稳定接口边界。
- `tests/`：官方 Playwright 游戏客户端与完整流程专项脚本。
